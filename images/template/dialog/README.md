# Dialog template folders

`dialog` templates are grouped by task or shared maintenance purpose:

- `wuhuan/` - 五环 task dialog options.
- `wubei/` - 五倍 task dialog options.
- `xiuluo/` - 修罗 task dialog options.
- `maintenance/` - shared maintenance dialogs, such as give-item, heal-pet, and repair-equipment options.
