# G184 授权版本政策连通性待验清单

本文件仅记录待验边界，不是已运行测试。用户未授权任何测试，不新增测试代码、不发送模拟验证请求。

## 运行中强制更新待验（BR-RELEASE-002，2026-09-20用户裁定）

- OPEN不得将status.ok当运行授权；设备不符、未绑定/legacy许可、未登记实例、错误secret都不能获得会话。并发修改绑定/许可/政策使OPEN的CAS失败，不得发出可用会话。
- CHECK按同一主库快照读取会话、绑定、许可和政策，拒绝被替换的旧会话或请求改报版本；政策撤销后下一次CHECK不能读旧允许缓存。CLOSE只能撤回自己的精确会话，不能误删并发新登录。
- 普通推荐新版本不阻断仍允许的旧版本；显式撤销要拒绝新任务，并撤销已在运行的旧版会话权限，不等当前轮完成。
- 客户端收到明确禁版后停止任务、取消待执行动作和后续输入；不可将禁版当网络故障无限重连。已完成的物理输入不能撤回。
- 全窗事件、四种输入提交、retained admission/terminal future、正在执行的独占回调都必须覆盖；撤权后仅中立松键鼠可继续。MapSurvey/启动future要异常完成，不能遗留等待者。
- UI停止持生命周期锁等worker退出时，transport收到拒绝不可同步反向等该锁；事件清理未完不能激活新登录，任一清理失败也不能假绿。
- 特别覆盖旧turn/observation/preflight生产者在重新登录之后才提交输入：只在入队时打代际不够，旧生产者不能取得新登录的权限。必须证明已退出或携带自身旧授权代际。
- Cloud后台明确拒绝时任务/MapSurvey被中断、未决命令返回STOPPED，旧worker再publish被拒；在无新业务请求时也能检测撤销，实际传播/停止耗时必须实测，2秒调度不等于2秒网络SLA。
- HTTP在初检成功后阻塞、撤销后返回：最终检查拒绝原业务body；响应已发头后撤销不能宣称撤回已发字节。旧handler未退出不能切新会话，CHECK慢返回/旧403不得替换或撤销新会话。
- MapSurvey中断不能提前释放仍在计算的旧worker占位；执行完成与撤销交错不得留下永久占位。云端callback任一失败须阻断新会话，不将清理异常当成功。
- 服务端拒绝不能依赖客户端弹窗；跨网络撤销传播时间须在后续验证中如实测量，不用未验证的“立刻”掩盖缓存宽限或仍可执行的排队动作。
- 禁版界面保持可用并明确要求更新，更新下载不被业务门误拦；更新后重新授权，任务不自动恢复。不影响仍被允许的版本。
- 以上为批准目标，双端撤权/线程代际/队列/HID/最终HTTP接线已编译未测试；政策保持关闭，不能将编译成功当上述竞态验收通过。

## 客户端专属大脑待验（BR-RELEASE-004）

- 客户端A/B即使同账号或同服务器也不能消费对方截图/回执、配置、记忆或任务；伪造客户端标识不得切换实例。
- 同一客户端多个游戏窗口属于其专属大脑，窗口级标识继续保留，不能串图/串输入。
- 客户端身份到专属实例的绑定必须由正式授权确认，重连/实例生命周期须保持一对一；这些接线尚未实现或测试。

## 受信更新待验（BR-RELEASE-003）

- Prod签名原始载荷与同Gamma包哈希，Client先验签再下载，包身份/体积/哈希不符不得安装。
- 拒绝非白名单HTTPS重定向、超量数据、路径穿越/重复ZIP目标、缺必需程序或配置树中的链接。
- 用户确认退出前不安装；父进程未退出/锁不可用时不切换；失败保留旧版本。
- 下载完成不等于安装成功，启动器按原子指针启动；新进程仍不得自动开始游戏任务。

- `LicenseAuthService.basePayload`必须将同一客户端版本传给verify/status；刷新不能漏版本。
- Worker两个真实入口读取对应app政策，在返回授权成功前按撤销、允许清单、最低版本顺序处理。
- disabled政策保留历史测试用法；enforced政策不接受未分软件的legacy-test码或缺少/非法版本。
- SQL管理员入口使用Cloudflare凭据；不可通过客户端HTTP修改政策；更新使用期望revision避免误覆盖。
- Cloud已有每请求会话门但缺运行中撤销闭环，不将入口拒绝等同在途任务已经停止。正式公共分发保持关闭。
- 部署证据以编译产物、Cloudflare部署版本及只读库状态为准，不以此声称以上行为已测试。
