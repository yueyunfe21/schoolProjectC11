# G178 绿链代次隔离：待授权的合同规格（未实现/未运行）

- 先发布第一段terminal，再注册第二段；旧消息高于phase游标也不能结束第二段等待。
- 旧terminal比有效combat更晚时，过滤必须先于选最新；不得推进统一游标而吞掉combat/预算消息。
- 第一段镜像迟刷新时即使prepared唤醒，第二段也不得用镜；新段ACTIVE保持等待，同段停步后方可继续。
- 每次重按同名绿链换UUID，FIFO需求收到本次生成ID，不反读旧镜像。
- 旧API调用、维护NPC等待、回接等待、战斗和预备动作唤醒语义不变；轮次/恢复/退出清绑定。
- 缺新段镜像不进入业务，UNKNOWN同腿原规则保留；暂停/停止不阻塞ready发布锁。
