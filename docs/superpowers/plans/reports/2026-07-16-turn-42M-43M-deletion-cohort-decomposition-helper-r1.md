### 42A compile-safe 分解

1. 43A gate 之后先重扫。当前零 inbound 的 `HttpRemoteCommandTransport`、`HttpRemoteTaskRunApiClient`、`RemoteTaskRunLifecycleService` 只是入口 anchors；不得据此单独宣告整个 42A 可拆。
2. `RemoteTaskRunLifecycleService -> RemoteCommandPollingLoop`；poller 又消费 handler、transport、API、registry 与 ledger。移除 lifecycle anchor 后才可能让 poller 失去 inbound。
3. `RemoteTaskRunRegistry <-> RemoteOperationLedger` 是直接双向边；二者还同时被 handler、poller、lifecycle 消费。它们必须在完整 42A patch 中共同处理，不能在二者之间放 compile gate。
4. `RemoteCommandTransport`、`RemoteCommandTransportException`、`RemoteTaskRunApiClient` 与 `RemoteCommandHandler` 当前均有旧图 caller，所以当前都是 REWIRE。
5. 42A 完整 patch 后只执行一次该 cohort 的 future named guard 与 DHXY compile；若需要中间核验，只能做只读引用扫描，不能把半拆源码交给下一 cohort。
